# 数据字典

JSON顶层：schema、protocol、exported_at、runs。每个run对应一个匿名参与者的一项实验。

| 会话字段 | 内容 |
|---|---|
| id / participant | 会话唯一ID / 匿名编号 |
| experiment | search或ratio |
| mode | formal、demo、test |
| protocol / version | 协议和软件版本 |
| preregistration | 收数前预测提交和文件校验信息 |
| assignment / seed | 编号分配序号、会话随机种子 |
| mapping | F/J与缺口方向的对应 |
| consent_version / consent_at | 知情同意版本 / 本次实验沿用的同意时刻 |
| experiment_order | 实际开始过的实验顺序 |
| environment | 进入实验时窗口、设备像素比与短浏览器信息 |
| status / completed_at | 状态与完成时刻 |
| trials | 所有作答、练习、技术无效与重做尝试 |
| schedule_summary | 完成后的计划区块和试次数摘要 |
| upload / upload_history | 最近回执 / 按项目码分别保存的回执；状态local、sending、confirmed、uncertain、error |
| withdrawn / withdrawn_at | 本地撤回标记与时刻，原始存档保留，后续分析和上传排除 |
| runtime_versions | 会话运行期间涉及的软件版本，恢复旧进度时可包含多个版本 |
| block_restarts / pending_trial | 区块恢复次数 / 中断时已知的待响应刺激规格 |

| 逐试次字段 | 内容 |
|---|---|
| trial_id / attempt_id | 计划试次ID / 本次尝试唯一ID |
| attempt_number | 当前计划位置的技术替代次数 |
| variation_index | 区块恢复次数×1000＋技术替代次数；搜索随机化使用seed＋variation_index×7919 |
| stimulus_seed / runtime_version | 比例替代图形生成种子（首次用原始值）/ 本次尝试的软件版本 |
| phase / section | practice/formal；classic/aid/ratio |
| block_index / trial_index | 区块和区块内序号，从0开始 |
| seed | 刺激随机种子 |
| rt_ms / onset_ms | 软件起点至反应的毫秒数 / performance.now起点 |
| trial_elapsed_ms | 注视开始至响应/结束的整试次时长 |
| response / timeout | 按键或数字响应 / 超时标记 |
| technical_invalid / excluded_reason | 技术无效与排除理由 |
| search_type / set_size | feature/conjunction、24（精简版固定） |
| target_side / gap / correct | 目标半屏、缺口方向、方向辨认正误 |
| policy / reliability | always/gated；high/low模拟状态 |
| potential_valid / cue_shown / cue_side | 潜在线索正确性、实际显示标记、方向 |
| chart_type / support | bar/pie；none/aligned |
| values / labels / rotation | 五个原始数值、对应成分、饼图旋转 |
| true_ratio / estimate | A/B真实百分数与回答 |
| absolute_error / signed_error | 绝对误差/有符号偏差，百分点 |
| log_absolute_error | log2(AE+1/8) |

CSV把会话字段重复写入每行，数组以JSON文本保存。课程接口使用较小的扁平逐试次载荷，labels转为短字符串、values为数字数组，rt字段为反应时。超时rt=-1并带timeout=true；原始导出rt_ms=null。

课程上传的逐试次字段还包含phase、status、实验内部名称、按键映射、会话起止时刻与同意信息，便于从平台CSV恢复配对分析。平台的固定列与同名试次列分别保留；导入时读取trial.created_at、trial.experiment、trial.trial_index等原始列。平台CSV可从网页的“数据与结果→导入记录”载入。

分析在副本中根据原始按键和映射重算correct，根据原始估计及图形真值重算误差，原始行保留。CSV包含consent_at、撤回和替代审计字段；JSON还保留完整会话元数据。CSV导入先核对整批结构、真实比例、条件数和重复ID，全部通过后合并。撤回标记经JSON/CSV往返保持。

未显示的潜在线索只用于匹配和核对，不当作参与者实际受到的误导。浏览器软件起点不代表已测到屏幕物理发光时刻。
