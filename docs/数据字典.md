# 数据字典（协议v4）

JSON导出schema为attention-lab/export-v1；每个run记录一个匿名参与者的一项实验。历史协议保留原字段，本表描述attention-v4-two-condition-20261107。

| 会话字段 | 内容 |
|---|---|
| id / participant / experiment | 唯一会话ID、匿名编号、search/ratio |
| version / protocol | 软件2.1.0、协议v4 |
| mode / status | formal/demo/test；active/complete/review |
| preregistration | 预测文件、SHA-256及本地Git提交 |
| mapping | f:present，j:absent |
| consent_version / consent_at | 本版知情同意版本与时刻 |
| experiment_order / assignment | 实际开始顺序、编号分配索引 |
| seed / environment | 会话种子、窗口宽高、像素比、浏览器摘要 |
| trials / cursor / pending_trial | 全部尝试、进度、中断时的刺激规格 |
| blocks / schedule_summary | 运行计划；完成后以摘要保留 |
| block_restarts / runtime_versions | 区块恢复次数、运行版本历史 |
| upload / upload_history | 按项目保存local/sending/confirmed/uncertain/error回执 |
| withdrawn / withdrawn_at | 撤回状态与时刻 |

| 通用试次字段 | 内容 |
|---|---|
| trial_id / attempt_id | 计划试次ID、本次尝试ID |
| phase / section / condition | practice/formal；search/ratio；条件名 |
| block_index / trial_index | 零起点区块、区块内序号 |
| seed / position_seed / stimulus_seed | 原刺激种子、跨条件匹配位置种子、技术替代种子 |
| attempt_number / variation_index | 技术替代次数；区块恢复×1000＋替代次数 |
| runtime_version | 试次运行时版本 |
| onset_ms / rt_ms / trial_elapsed_ms | 软件绘制起点、反应时、含准备的试次总时长 |
| rendered_width / rendered_height | SVG元素CSS像素宽高 |
| timeout / technical_invalid / excluded_reason | 超时、技术无效、排除理由 |
| correct | 根据原始作答及刺激重算；搜索为存在判断，比例为较短段选择 |

| 搜索字段 | 内容 |
|---|---|
| condition | baseline/improved |
| search_type / set_size | conjunction / 30 |
| target_present / target_zone | 是否出现绿色T；目标八区域编号0—7，缺席为null |
| green_x / brown_t | 绿色X及棕色T的实际数量 |
| response | f/j；键位取物理KeyF/KeyJ优先，支持大写及输入法状态 |

原始基线缺席15棕T＋15绿X，出现时14棕T＋15绿X＋1绿T；改进缺席3棕T＋27绿X，出现时2棕T＋27绿X＋1绿T。每条件出现/缺席各10次。搜索布局由seed及variation_index确定，实际目标区与元数据一致。

| 比例字段 | 内容 |
|---|---|
| condition / separation | adjacent/0；separated/1 |
| chart_type | divided_bar |
| values / labels | 左柱自下而上4个长度值及内部标签；A为短段，B为长段；界面只画同样的圆点 |
| background_values | 右侧背景柱自下而上4段 |
| axis_max | 内部坐标轴上限600，显示端点0/100 |
| reference_height / case_index | 长段内部长度125/250、匹配材料编号 |
| shorter_position / shorter_response | 真正较短段及被试选择，upper/lower |
| true_ratio / estimate / response | 真实短/长×100、估计百分数、原数字响应 |
| absolute_error / signed_error | 绝对误差、有符号偏差，百分点 |
| log_absolute_error | log2(AE+1/8)，以0—100百分数计 |

左柱相邻目标索引为2、3，间隔目标索引为1、3（索引从0起）；点位处于对应段的中心。真值从values中A/B重新计算，选择正误从索引上下关系重算。超时估计和误差为null，correct=false。浏览器实际显示比例=min(rendered_width/640,rendered_height/580)，段长=内部值×0.8×该比例。

主要分析：搜索每条件先分别取出现/缺席正确RT中位数，再等权平均；两类各至少8/10个200—5000ms有效反应。比例主AE纳入全部成功提交且500—30000ms的有效数值，包括选段错误的数值回答。每条件有有效数值才形成配对指标；全部缺失时该配对记为缺失。valid为有效数值数量，correct_only_valid及correct_only_ae为仅选段正确时的补充数量及AE。每条件的有效数量、选段错误及超时分别报告。两项效应为基线−改进；比例时间代价为改进−基线。错误及超时保留报告。

CSV重复必要会话字段，数组以JSON存储。平台载荷中cond为条件，labels转逗号字符串，rt与rt_ms超时为-1；本地JSON超时rt_ms为null。平台实验名为visual_search_ratio_v4、graphical_ratio_spacing_v4。导入支持平台trial.前缀字段，并以试次自身的字段恢复条件、时间与协议。

分析在副本中重算派生值，原始记录保留。每位参与者、每实验仅取本协议最近一次完整正式记录；最新记录撤回时不回退使用更早记录。导入先整批核对，再合并，重复ID的不同原始内容进入核对。
