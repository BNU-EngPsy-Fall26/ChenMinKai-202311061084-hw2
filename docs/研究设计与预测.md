# 收数前研究设计与预测

协议：`attention-v2.1-20261101`。日期：2026年11月1日。状态：经用户授权开始实现的网站版，真实收数尚未开始。本文在本地Git中留存，提交哈希另记于build-info.js及逐会话元数据。

## 目标与范围

经典实验保留为概念复现基线。新增条件分别评估提示发布策略和任务相关辅助表示。每个实验由同一被试完成全部条件；两项实验先后自由选择并记录。计划12名成年人，目标至少10名有可分析数据，每实验至少5名他人。按预定人数招募；如技术/任务遵循排除造成不足，记录原因后补招，避免按效应显著性加人。

## A：视觉搜索

目标为橙色C，报告缺口左右，F/J映射在被试间平衡。每幅有唯一目标。经典部分为特征/联合搜索×8/16/24项×12＝72次，两个搜索类型区块顺序按编号交替。

改进部分固定24项联合搜索，自主/持续/择机提示各60次。每策略包含较可靠40次（30次潜在线索正确、10次错误）和低可靠20次（10次正确、10次错误）。状态为研究者受控的模拟参数，择机策略只读取可靠状态。线索半屏与目标缺口响应独立并尽量平衡。

目标：减少低可靠情境下的提示误导，保留较可靠情境下的帮助，并评估预设2:1混合场景中的总体取舍。

预测与比较：

1. 经典描述：联合搜索斜率大于特征搜索斜率，分别按每人三个集合大小的条件均值拟合。
2. **主要A**：低可靠情境，持续提示正确RT−择机提示正确RT＞0。
3. 次要：较可靠情境，自主搜索RT−择机提示RT＞0。
4. 次要：整体以较可靠:低可靠＝2:1等条件权重汇总，报告持续−择机RT、错误与超时；整体改进不由低可靠一类试次替代。
5. 描述：持续提示中正确与错误线索各自相对自主基准的收益/成本。

正确RT用于时间比较，错误和超时单独保留。所有试次目标存在，指标是方向辨认错误，不计算缺失目标任务的漏报、误报或d'。

## B：比例判断

任务为A/B×100的视觉估计，A<B。图形为五成分条形图或饼图，辅助为主图、原图复制窗、对齐比较窗。2×3×12＝72次。真实比值12个，在六条件匹配；非关键属性变动。六条件采用6阶平衡序列，每个序列用于两名计划参与者。

辅助窗自动出现，与主图同步，不含真实数值或计算答案。对齐窗保持原数值尺度，不把B归一到100；原图复制窗匹配额外显示面积。图形与辅助同时出现，整个观察与输入时间记作作答时长。

目标：降低A/B估计误差，同时评估时间代价。保留主图不等于已验证整体理解不受影响，本次不测眼动、神经指标或心理负荷。

预测与比较：

1. 经典描述：无辅助时饼图误差高于条形图。
2. **主要B**：饼图中，复制窗AE−对齐窗AE＞0。
3. 次要：饼图中，主图AE−对齐窗AE＞0。
4. 次要：对齐窗−复制窗作答时长，正值为额外时间。
5. 探索：辅助效果是否因主图类型而异。

AE=|估计百分数−真实百分数|，单位百分点。偏差=估计−真实。LAE=log2(AE+1/8)，使用0—100的百分数单位，精确回答对应−3。与1984年原文的材料、样本和汇总方式不同，比较时显式注明。

## 练习与技术处理

A经典18次，至少15次正确；辅助12次，至少10次正确。未达标准则新一组练习，全部保留练习记录。B练习12次，展示参考比值。体验和调试使用短流程并单独标记。

正式试次预先定数。错误不补试。失焦、切后台、暂停或渲染/尺寸异常尝试保留技术无效标记，使用新尝试替代。刷新/离开后继续将重做未完成区块，原区块尝试标记restarted_block，已完成区块保持有效。

## 有效数据与主要分析

仅纳入mode=formal、status=complete、当前协议会话的正式有效尝试；每名被试每实验取最近一次完整正式会话。重复导入按run ID去重。

A：总体正确率≥75%；主要RT只纳入正确且150—5000ms反应。经典每条件至少10/12个有效RT；辅助较可靠至少32/40、低可靠至少16/20。对应比较不足时记缺失。分解有效/无效线索时，30次格至少24、10次格至少8个有效RT。

B：估计值0—100，作答时长500—30000ms；每条件至少10/12个有效回答。超时记缺失，极大误差保留。

先按被试汇总每条件，再配对计算效应、均值及个体结果。每项比较报告实际有效n。达到5个配对才计算2000次按被试重抽样的探索性百分位bootstrap区间。配对置换在n≤16时穷举符号翻转，较大n采用20000次随机翻转。两项主要检验都可计算时，按A、B两检验族作Holm校正；经典与其他比较作为描述/次要/探索性。

不把“不显著”解释成两条件等价；不以正确提示的局部收益代替整体表现。改进无效或有代价时，保留预测并据实报告。
