# 工程心理学第二次作业 注意实验室

本项目在同一网页中实现视觉搜索与比例判断两项实验。两项实验均采用被试内设计，每名参与者完成一个基线条件和一个改进条件。5名匿名参与者P01—P05完成全部正式试次。

## 运行方法

1. 克隆或下载本仓库。
2. 使用Chrome或Edge双击根目录的`index.html`。
3. 输入匿名编号并确认知情同意。
4. 从实验选择页进入视觉搜索或比例判断任务。

正式任务使用电脑和横向窗口，建议窗口尺寸不小于1000×620。网页使用HTML、CSS和JavaScript实现，本地资源均采用相对路径。实验可直接在本地打开；向课程收数平台提交记录时需要联网。

## 实验一 视觉搜索

目标为绿色T，干扰项为棕色T和绿色X，画面始终包含30个项目。

- 基线条件：目标缺席时包含15个棕色T和15个绿色X。
- 改进条件：目标缺席时包含3个棕色T和27个绿色X。
- 目标出现时，以1个绿色T替换1个棕色T。
- 每条件20个正式试次，其中目标出现和缺席各10次。
- F键表示目标出现，J键表示目标缺席。

预测：减少与目标同为T形的干扰项后，需要检查的同形候选范围缩小，正确反应时将缩短。正确率用于同时评价搜索速度和判断准确性。

## 实验二 比例判断

画面包含A、B两根四段柱。A柱中两个圆点标记的分段为比较目标，参与者先选择较短段，再估计该段占较长段的百分比。

- 基线条件：两个目标段相邻。
- 改进条件：两个目标段之间放置1个原有的未标记分段。
- 每条件10个正式试次。
- 配对材料保持目标段长度、较短段相对位置和B柱内容一致，仅改变A柱的分段排列。

预测：间隔布局的平均绝对误差AE较小。作答时间用于评价布局带来的读取成本。

收数前预测文件见[研究设计与预测](docs/研究设计与预测_20261107_v4.txt)，对应提交为`17e32dd8b723df68b2dea415ea006a1d392c6be7`。

## 数据收集

网页逐试次记录匿名编号、实验条件、刺激参数、作答、正确性和反应时。每项正式实验完成后，程序将记录提交至课程项目`XYVTBN`。课程收数页面为<https://attention-lab-production.up.railway.app/hw2>。

本次分析包含5名参与者、10份完整实验记录和300个正式试次：视觉搜索每人40次，比例判断每人20次。

## 结果

| 指标 | 基线条件 | 改进条件 | 基线减改进 |
|---|---:|---:|---:|
| 搜索正确反应时 | 1879.83 ms | 1274.87 ms | 604.96 ms |
| 搜索正确率 | 86% | 94% | −8个百分点 |
| 比例判断AE | 11.42个百分点 | 10.18个百分点 | 1.24个百分点 |
| 比例判断作答时间 | 5063.05 ms | 5336.08 ms | −273.03 ms |

视觉搜索中，5名参与者在改进条件下的正确反应时均缩短，平均缩短604.96 ms，相当于基线的32.18%；整体正确率提高8个百分点。标准化配对效应量`d_z=1.63`，双侧精确符号翻转检验`p=0.0625`，两项主要比较的Holm校正结果为`p=0.125`。

比例判断中，间隔布局的平均AE下降1.24个百分点。P01和P05的误差下降，P04基本持平，P02和P03的误差增加，配对差中位数为0.02个百分点，标准化配对效应量`d_z=0.36`。间隔布局的平均作答时间增加273.03 ms，因此该布局的评价同时结合误差、时间和个人差异。

视觉搜索结果表明，在总项目数保持30时，减少与目标形状相同但颜色不同的干扰项，可以缩小需要检查的候选范围。比例判断结果表明，目标分段的位置关系会改变读取表现，平均误差变化同时伴随时间成本和个体差异。

完整结果与讨论见[实验报告](report/工程心理学第二次作业实验报告.docx)。
