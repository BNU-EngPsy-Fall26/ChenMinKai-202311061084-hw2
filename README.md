# 注意实验室

项目码：**XYVTBN**。软件2.1.2，协议`attention-v4-two-condition-20261107`。

## 运行

双击根目录“打开注意实验室.html”，或本仓库index.html。网页使用HTML/CSS/JavaScript，无需安装依赖。正式任务使用电脑，窗口至少1000×620。匿名编号登录并同意参与后，可选择搜索或比例判断。

| 任务 | 原文献基线 | 改进条件 | 每人正式试次 |
|---|---|---|---:|
| 搜索 | 绿色T目标；棕色T/绿色X干扰近似等量 | 同样材料、30项，干扰比例改为3∶27 | 20×2＝40 |
| 比例判断 | 同柱中两个点标记分段相邻 | 一个既有分段位于两个标记段之间 | 10×2＝20 |

搜索判断绿色T是否出现：F为出现，J为其余画面。目标出现和缺席在每条件各10次。比例任务先选择较短的标记段，再输入它占较长段的百分数。基础练习各4次；两项正式合计60次，预计7—10分钟。体验单独标记为demo。

## 设计与预测

固定5名他人，全部完成两个任务的所有条件。每项仅一个主要配对比较。搜索采用绿色T、棕色T与绿色X的结合特征搜索，比较等量与偏置干扰项比例（Treisman与Gelade，1980）。比例任务采用两根四段柱、同柱两个圆点标记，比较标记段相邻与间隔一段的布局（Cleveland与McGill，1984）。

收数前预测：[本版设计与预测](docs/研究设计与预测_20261107_v4.txt)。冻结预测原件保留原内容与校验。当前分析采用all-available-v1，见[数据字典](docs/数据字典.md)。

预测：搜索偏置比例的正确反应时较短；比例间隔一段的AE较小。两项效应均以“基线−改进”计算。错误、超时和比例作答时间同时报告。5人用于课程小样本复现，不保证显著；精确双侧符号翻转检验最小p为0.0625。

搜索固定30项，不估计搜索斜率。比例只测两种排列，不估计最优间隔。比例材料的参考长度和较短段上下位置分别平衡；每两个试次含两条件各一次。SVG自适应缩放并记录实际显示尺寸。比例主AE纳入全部有效数值回答，选段正确率、超时、作答时间及仅选段正确时的AE另行报告；每条件的实际有效数公开呈现。当前计分规则见数据字典。

## 结果与讨论

5名他人P01—P05完成两项任务，共10份完整正式记录、300个正式试次。搜索每人每条件20次，比例每条件10次；全部会话保存知情同意时刻和项目XYVTBN的确认上传回执。每人搜索后完成比例；搜索条件区块3∶2平衡，比例按材料组内平衡呈现。两项基础练习各4次，P02额外完成4次搜索练习。

| 指标 | 基线 | 改进 | 基线减改进 |
|---|---:|---:|---:|
| 搜索正确反应时 ms | 1879.83 | 1274.87 | 604.96 |
| 搜索正确率 | 86% | 94% | −8个百分点 |
| 比例判断AE 百分点 | 11.424 | 10.184 | 1.240 |
| 比例判断作答时间 ms | 5063.05 | 5336.08 | −273.03 |

搜索5人的反应时均缩短，平均降幅32.18%，配对效应d_z=1.63，双侧精确符号翻转p=0.0625，Holm校正p=0.125。搜索条件的正确率提高8个百分点，计入反应时的正确试次分别86和94次；改进条件有1次超时，计入错误率。

比例判断P01、P05误差下降较明显，P04接近持平，P02、P03误差上升。平均AE下降1.24个百分点，配对差中位数0.02个百分点，d_z=0.36，双侧精确p=0.5625，Holm校正p=0.5625。较短段选择正确率均100%；间隔布局平均用时增加273.03 ms。两条件平均有符号偏差分别−10.98和−8.50个百分点，均为低估。

原文对照：Treisman与Gelade（1980，表1）中结合搜索对显示数量敏感；本次在30项显示内比较干扰项组成，结果体现候选集合组织与效率的关系。Cleveland与McGill（1984，图16及18）显示Type5长度判断误差及中等比例低估；本次基线低估方向与其观察相符，间隔排列的效果由本次配对结果评价。

应用上，搜索收益体现在速度与正确率的同向改善；比例布局需要结合误差、读取时间和个体差异评价。结论对应5人及本次材料、显示参数和任务安排。

复算：运行`node analysis/analyze-data.cjs <原始JSON路径>`生成汇总；`analysis/independent-check.py`按原始作答独立复核评分和配对结果。分析资料与黑白报告位于交付目录“04_分析与报告”。

## 保存与恢复

逐试次保存到当前浏览器的`attention-lab:study-v2`。协议字段区分新旧设计；打开新版会保留历史记录，旧版作答不计入新版完成数或结果。文件入口与HTTP入口通常使用不同的浏览器存储空间，换设备也需要导出/导入转移记录。

JSON保留全部尝试、练习、技术无效和撤回状态；CSV提供逐行字段。暂停、失焦、切后台或改变尺寸会标记当前尝试技术无效。恢复刷新后重做当前区块，旧行保留并标记排除。普通错误及超时不补试。

本地清空由“更多→研究者视图→更多→清空本机记录”确认触发；平台记录在收数站管理。新版本不会自动删除作答。

## 课程收数

项目XYVTBN已配置自动上传。每完成一项正式任务，程序向`https://attention-lab-production.up.railway.app/api/hw2/submit`发送一次请求：

- `visual_search_ratio_v4`：40个正式试次，condition逐行标记baseline/improved。
- `graphical_ratio_spacing_v4`：20个正式试次，condition逐行标记adjacent/separated。

平台顶层condition留空，逐试次cond记录被试内条件。练习、体验、技术无效记录和历史协议不上传。项目码为公开配置，下载密钥由创建者保存在[课程收数站](https://attention-lab-production.up.railway.app/hw2)。本地HTML上传需要联网。

收到HTTP成功且`ok:true`才标记平台已确认。失败或回执不确定时保留本地记录，界面显示待重试/核对。收数站核对后可手动重试；重复点击发送中或已确认的记录会合并/略过。网页支持导入本地JSON/CSV及平台逐试次CSV；条件和协议核对后再合并。

“数据与结果”展示当前协议中每人每实验最近一次完整正式记录。统计先按人汇总，再计算配对差；直接使用已有可计算数据，按实际数量显示，不设正确率、有效试次数、反应时截断或人数准入门槛。搜索反应时使用正确作答，错误计入正确率；超时与技术中断单独保留。旧版、体验、练习与撤回数据单独保留。程序随附5名参与者的真实匿名汇总，研究者视图可直接查看结果。
