# 注意实验室

工程心理学第二次作业：经典注意实验的概念复现与显示改进。两个实验在同一页面，通过匿名编号登录后选择。

## 打开

双击本目录的 **index.html**，或上一级的 **打开注意实验室.html**。使用电脑上的 Microsoft Edge 或 Chrome，窗口至少1000×620。网页使用自绘SVG和本地脚本，离线可运行、保存和导出，运行无需安装依赖。

参与流程：匿名编号与知情同意 → 选择实验 → 指导语 → 练习 → 正式区块 → 保存记录。界面采用简明肯定句；说明与研究者功能分开。

首页的“先体验”使用短流程，记录标为 `demo`，与正式数据隔离。`?qa=1` 是独立调试环境，数据标为 `test`，存储也隔离；正式收数使用默认地址。

## 两个实验

| 实验 | 经典复现 | 新增条件与目标 | 正式试次 |
|---|---|---|---:|
| 视觉搜索 | 单特征/联合搜索 × 8/16/24项，每格12次 | 自主搜索、持续提示、择机提示；评估低可靠提示的误导成本与选择性帮助 | 72＋180＝252 |
| 比例判断 | 无辅助条形图与饼图的比例判断 | 主图、原图复制窗、对齐比较窗；评估比例误差与时间代价 | 2图形×3辅助×12＝72 |

同一被试完成各实验内全部条件。实验先后由参与者选择并记录；实验内部区块和按键映射按编号平衡。首次给参与者分配唯一编号P01、P02……，在两个实验中使用同一编号。

视觉搜索的目标为橙色C，F/J报告缺口方向。所有试次目标存在。提示箭头指候选半屏，目标缺口方向与位置、箭头方向尽量独立。每种提示策略60次：较可靠40次（30对/10错）、低可靠20次（10对/10错）。择机策略仅根据预设可靠状态显示箭头，较可靠状态仍有错误；模拟辅助并非实际AI模型。

比例判断回答“A是B的百分之几”。对齐窗将A、B按原数值尺度绘为共同基线条形，主图保留；B保持原值，图中呈现目标标记。原图复制窗提供额外显示的对照。六条件的真实比例分布匹配。

完整收数前研究设计和预测见 [研究设计与预测](docs/研究设计与预测.md)，协议差异见 [协议变更记录](docs/协议变更记录.md)。

## 计时、恢复与数据

刺激通过 `requestAnimationFrame` 安排绘制，以 `performance.now()` 记录软件起点和首个有效响应；并保存整试次用时。浏览器和设备有显示、输入延迟，这不是硬件级计时保证，正式参与优先统一电脑与浏览器。

搜索试次：注视500ms → 箭头或中性点300ms → 空屏200ms → 刺激与响应（最长5秒）→ 空屏300ms。比例试次：注视500ms → 图形与输入 → 回答（最长30秒）→ 空屏300ms。练习提供700ms反馈。

切后台、失焦、窗口改变和暂停会保留技术无效尝试。恢复当前页面时使用新的刺激随机化尝试；刷新/退出后继续则重做未完成区块，之前的该区块记录保留并标记 `restarted_block`。组间休息不影响已完成区块。

每次作答自动保存到当前浏览器，完成页提供JSON与CSV。JSON包含匿名会话与原始尝试；CSV一行一个尝试，包含练习与质量标记。正式分析以 `phase=formal`、有效尝试和预先规则筛选。

已完成记录保留实际刺激、随机种子和顺序摘要，去除重复的计划数组，降低本地存储占用。浏览器保存空间不足时界面提示下载备份；数据仍保留在当前页面。建议每位参与者完成后下载一份JSON到指定作业目录。

## 数据与结果

右上角“更多” → **研究者视图**，可导入本网页导出的JSON/CSV、查看真实结果、下载全部记录和导出离线结果快照。参与者完成两项正式实验后也可查看结果。

当前交付含 **0名真实被试**；结果页保持空数据状态。体验、调试、练习和未完成记录均与正式结果分开。多次导入按run ID去重，每名被试每实验取最近一次完整正式会话，质量不足者在对应比较中标记缺失。

结果先按被试汇总，再进行配对分析：

- 搜索主要比较：低可靠情境，持续提示RT−择机提示RT；并列显示错误率、高可靠收益与2:1加权整体表现。
- 比例主要比较：饼图中，原图复制窗AE−对齐比较窗AE；另报告作答时长代价。
- 经典比较：联合−特征搜索斜率，及无辅助饼图−条形图误差。
- 达到5个有效配对后计算被试层面的探索性95% bootstrap区间与配对置换；两个主要检验均可计算时报告Holm校正结果。

原文与本项目按方向、可比指标及方法差异解释。页面展示AE和经典LAE，采用自绘材料与小样本，属于概念复现。真实收数后，由作业作者完成结果解释与讨论。

导出的 `results-data.js` 可以替换 `dist/js/results-data.js`，把当时的真实匿名汇总固化到离线网站；本地存在正式原始记录时优先分析当前数据，空本地数据时展示归档快照。

## 课程接口

研究者菜单 → 课程项目，填入 [课程平台](https://attention-lab-production.up.railway.app/hw2) 生成的6位项目码。下载密钥由课程项目页面保管。当前交付的项目码为空，自动提交默认关闭。

一个完成的正式实验提交一次。接口实验名为 `visual_search` / `graphical_ratio`；被试内条件写在逐试次字段，顶层 `condition` 留空。发送前检查256KB限制，只发送正式有效尝试，并保留错误、超时和重建刺激所需参数。原始练习、技术无效、旧区块记录留在本地导出中供审计。

收到 `{ok:true}` 才记录平台确认；网络或回执不确定时保留本地记录并标记待核对，人工确认平台记录后才重试。调试与体验数据在上传入口被过滤。

本轮只实现接口适配，未创建课程项目、上传数据、托管或向课程GitHub提交。实际接口联调待项目码建立后进行。
